Analysis 2: What happens when we replace different residues with alanine?

Author

Luis Sebastian Galán, Laura Grenaa Jensen, Taniya Dey and Thota Kanishka Rao

What are we looking at?

We want to see which types of amino acids show the biggest changes in binding when replaced with alanine. We first compare the chemical groups using all alanine mutations together. Then we check which differences are still there after accounting for the chain and structure.

We use 328 experimental \(\Delta \Delta G\) measurements. A positive value means that the mutation weakened binding compared with the original complex.

Select and describe the alanine mutations

We select mutations to alanine using to_alanine from the augmentation step. We keep rows with a recorded \(\Delta \Delta G\), chemical group, mutation location, and structure pdb so we can use the same rows in every model.

Which amino acids had the highest mean \(\Delta \Delta G\)?

We start by comparing the mean experimental \(\Delta \Delta G\) for each starting amino acid. Some amino acids were measured only once or twice, so we show how many measurements and complexes are behind each mean.

alanine_summary <- dat_alanine |>
  group_by(mut_from, type_from) |>
  summarise(
    n_measurements = n(),
    n_complexes = n_distinct(pdb),
    mean_ddg = mean(ddg),
    median_ddg = median(ddg),
    sd_ddg = sd(ddg),
    .groups = "drop"
  ) |>
  mutate(
    se_ddg = sd_ddg / sqrt(n_measurements),
    df = if_else(n_measurements > 1, n_measurements - 1, NA_real_),
    margin = qt(0.975, df = df) * se_ddg,
    ci_lower = mean_ddg - margin,
    ci_upper = mean_ddg + margin
  ) |>
  select(-sd_ddg, -se_ddg, -df, -margin) |>
  arrange(desc(mean_ddg))

Do the chemical groups differ?

Some amino acids had only a few measurements, so we group the mutations by the chemical properties of the starting amino acid. We start with a one-way ANOVA to test whether mean \(\Delta \Delta G\) differs across the chemical groups. At this point we pool mutations from all locations and structures.

model_pooled <- lm(
  ddg ~ type_from,
  data = dat_alanine
)

Which differences remain after adjusting for location and structure?

Some chemical groups may have been tested more often on certain chains or in certain structures. To account for this, we fit two models that both include mutation location (mutation_category) and PDB ID (pdb). We add chemical group to the second model and test whether it improves the fit.

  ddg ~ mutation_category + pdb,
  data = dat_alanine
)

model_adjusted <- lm(
  ddg ~ type_from + mutation_category + pdb,
  data = dat_alanine

We then compare the chemical groups two at a time in both the pooled and adjusted models. We use Holm’s method to adjust the p-values within each set of comparisons.

The estimates are mean differences in kcal/mol. For example, a positive estimate for aromatic - polar means the aromatic group had a higher estimated mean \(\Delta \Delta G\)

pooled_means <- emmeans::emmeans(model_pooled, specs = "type_from")
adjusted_means <- emmeans::emmeans(model_adjusted, specs = "type_from")

pooled_pairs <- emmeans::contrast(

  as.data.frame() |>
  select(

Do the differences vary by mutation location?

What did we find?

After accounting for mutation location and structure, mean \(\Delta \Delta G\) was 0.95 kcal/mol higher for aromatic-to-alanine mutations and 0.78 kcal/mol higher for positive-to-alanine mutations than for polar-to-alanine mutations (Holm-adjusted p = 0.000702 and p = 0.0175).

With all rows included, the differences varied by mutation location (p = 0.0139). Both pairs differed on the heavy chain, and only positive–polar differed on the light chain. The direct comparisons between locations were inconclusive. We found no clear evidence that the differences varied by structure (p = 0.412).
